# Zervo

An integrated B2B and B2C workforce marketplace and on-demand local services platform connecting gig workers, dark stores, logistics operators, and service professionals.

## 🚀 Tech Stack

- **Frontend / Framework:** Next.js, React, TypeScript, Tailwind CSS
- **Backend & Database:** Supabase, PostgreSQL, Node.js
- **Deployment:** Vercel

## 📂 Project Structure

- `src/` - Application source code (components, pages, APIs)
- `public/` - Static assets and images
- `firestore.rules` - Security rules for Firebase/Supabase integrations
